# 고요 (Goyo) 0.4

아이폰 디지털 디톡스와 공부 기록 **전체 앱**입니다.

- 전체 앱 **Goyo**: 스크린 타임 연동, 잠금·허용 앱, 공부 집중 화면, 전화·문자 메뉴, 아이콘 꾸미기, 내장 웹 필터.
- 동반 앱 **GoyoBrowser**: 스크린 타임 없이 쓰는 공부 도구와 내장 브라우저.

**Actions → Goyo iPhone IPA → Goyo-IPA**가 전체 앱 빌드입니다. 전체 앱과 스크린 타임 확장 3개가 들어 있습니다.
자동 빌드의 IPA는 미서명 파일이며, 실제 스크린 타임 사용에는 Family Controls·App Group을 가진 Apple 개발자 서명이 필요합니다.

인증서와 프로비저닝을 준비하면 **Actions → Goyo signed iPhone app**에서 전체 설치 파일을 서명할 수 있습니다.
GoyoBrowser를 무료 계정으로 다시 서명하는 방식으로는 시스템 스크린 타임 권한이 생기지 않습니다.
