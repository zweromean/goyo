# 고요 (Goyo) 0.4.1

현재 설치용 빌드는 **GoyoStandalone**입니다. 공부 타이머·기록·투두·캘린더, SNS 웹 필터, 전화·문자, 허용 앱 메뉴, 아이콘 꾸미기를 모두 포함합니다.

스크린 타임·Family Controls 실행 코드는 설치용 바이너리에서 제외했습니다. 관련 창과 설정 항목은 남겨두었으며 값만 저장합니다. 권한 요청, 시스템 앱 차단, 가족 승인, 기기 전체 삭제 제한은 실행하지 않습니다. Family Controls·App Group entitlement와 확장도 포함하지 않습니다.

**Actions → Goyo iPhone IPA → GoyoStandalone-IPA**를 다운로드해 압축을 풀고 `GoyoStandalone-unsigned.ipa`를 Sideloadly에서 서명·설치하세요. 미서명 IPA 자체는 바로 설치되지 않습니다.

기존 스크린 타임 연동 소스와 Goyo 타깃은 저장소에 보관했습니다. 현재 설치에는 Goyo-IPA가 아닌 **GoyoStandalone-IPA**를 사용하세요.
