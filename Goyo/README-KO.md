# 고요 0.4 — 아이폰 디지털 디톡스 앱

한국어 SwiftUI 앱 소스와 Xcode 프로젝트입니다. iOS 17 이상을 대상으로 합니다.
전체 Goyo와 GoyoBrowser의 실제 iPhone용 Release 빌드가 GitHub Actions에서 성공했습니다. 자동 빌드 파일은 미서명 IPA입니다. 스크린 타임을 실제 기기에서 사용하려면 전체 Goyo와 확장 3개에 Family Controls·App Group 프로비저닝이 포함된 개발자 서명이 필요합니다.

## 0.4 추가 기능

- 스크린 타임 허용 앱·웹사이트 목록. 선택 앱과 카테고리 잠금에서 예외로 적용됩니다.
- 공부 중 허용 목록만 사용: 목록 밖의 앱과 웹사이트를 차단합니다.
- 어두운 공부 집중 화면: 현재 집중 시간, 오늘 누적, 과목별 카드, 실제 공부 구간 타임라인.
- 일시정지·재개. 쉬는 시간은 공부 합계에서 빠지고 공부 중 잠금은 유지됩니다.
- 집중 화면 더보기: 화면 유지, 메인 시간 선택, 메모, 타이머·스톱워치, 계산기, 백색소음, 전화·문자.
- 세 번째 참고 이미지에 맞춘 전화 메뉴와 숫자 키패드. 연락처 번호 선택과 시스템 전화 연결.
- 고요 안의 시스템 문자 작성 화면. 전송은 사용자가 확인하고 누릅니다.
- 웹사이트와 설치 앱을 추가하는 허용 메뉴. 웹사이트는 내장 브라우저, 설치 앱은 URL 스킴 연결.
- 메뉴 아이콘은 사진·기호로 꾸미고, 고요의 iPhone 홈 화면 아이콘은 기본·초록·밤·종이 중에서 변경합니다.
- 쇼츠 선반뿐 아니라 모바일 쇼츠 탭 전체를 숨깁니다. 직접 쇼츠 주소도 차단합니다.
- 앱 설치 배너·앱에서 열기 창 숨김. 앱스토어·설치 링크로 전환하는 요청을 차단합니다.

참고 사진의 그룹 카드 형태는 본인의 과목별 카드로 구현했습니다. 다른 사람의 가짜 공부 기록을 표시하지 않으며, 온라인 공부 그룹 서버는 포함하지 않습니다.

| 공부 시간·과목별 오늘/이번 주 통계 | 기기 내 저장, 화면을 꺼도 계속 측정 |
| 공부 중 SNS 잠금 | 고요 SNS 진입 + 전체 버전에서 선택한 기존 앱 |

| 갤러리 허용·차단 목록 | ID/주소 입력, 최대 100개, 설정 비밀번호 적용 |
| 과목별 색상·집중도 별점 | 과목 편집, 공부 기록별 1~5점, 나중에 평가·수정 |

각 필터는 개별로 켜고 끌 수 있으며 설정은 기기에 저장됩니다.
대기 중 앱을 나가면 시간이 멈춥니다. 대기가 끝나도 ‘계속하기’를 눌러야 열립니다.

## 기능 사용법

### 디시인사이드

‘필터 → 개념글 · 갤러리 제한’에서 개념글 전용 모드와 갤러리 제한 방식을 설정하세요.
‘허용’ 방식은 목록에 넣은 갤러리만 열고, ‘차단’ 방식은 목록에 넣은 갤러리만 막습니다.
허용 방식에서 목록이 비어 있으면 모든 갤러리를 막습니다. 제한 없음은 갤러리 목록 제한을 해제합니다.
ID 또는 모바일·PC 갤러리 주소를 입력할 수 있고 목록은 최대 100개입니다.
홈에서 디시인사이드를 열고 위쪽 입력란에 ID/주소를 넣거나 ‘갤러리 목록’에서 선택하세요.
다중 계정 저장소와 진입 대기도 디시에 적용됩니다.

개념글 전용 모드는 목록에 `recommend=1`(모바일) 또는 `exception_mode=recommend`(PC)를 적용합니다.
페이지가 실제로 개념글 탭을 선택했는지 확인하고, 목록 행에서 추출한 같은 갤러리의 글 번호만 현재 세션에 허용합니다.
공지, 본문 속 링크, 옆 영역의 글 링크는 허용 글 번호를 추가하지 않습니다.
직접 글 주소에 개념글 쿼리만 붙여도 목록에서 확인되지 않은 글은 열리지 않습니다.
개념글을 확인할 수 없는 웹 구조에서는 화면을 가립니다. 사이트 구조가 바뀌면 `DcFilters.js` 선택자를 갱신해야 합니다.
모바일 일반·마이너/미니 경로와 PC 일반·마이너·미니 목록/본문 경로를 처리합니다.
앱의 갤러리 ID 입력은 일반 모바일 `/board/ID` 주소를 엽니다. 미니 갤러리는 `/mini/ID` 주소 전체를 입력하세요.
주소 전체를 넣으면 모바일/PC 갤러리 경로를 유지하면서 목록을 엽니다.
디시 브라우저는 갤러리 목록·본문과 로그인 페이지에 한정합니다. 외부 뉴스·기타 디시 서비스는 열지 않습니다.
디시 게시물 수는 현재 시청 알림 집계에 포함하지 않습니다.

### 다중 계정

홈의 ‘설정 → 다중 계정’에서 계정을 추가하고 이름을 지정하세요. 각 서비스마다 최대 10개를 저장합니다.
홈 또는 브라우저 상단 계정 메뉴에서 전환한 뒤 웹 서비스에 직접 로그인하세요.
추가 계정은 `WKWebsiteDataStore(forIdentifier:)`로 쿠키·로그인 정보를 분리하여 지속 저장합니다.
첫 계정은 이전 버전의 기본 저장소를 유지합니다. 서비스의 로그인 성공 여부는 실제 아이폰에서 확인해야 합니다.
고요는 계정 비밀번호를 별도 수집하거나 저장하지 않습니다.

### 알림·휴식

‘필터’에서 게시물 수 알림, 기준 개수, 휴식 화면, 지속시간을 각각 설정하세요.
유튜브는 일반 영상의 재생 위치가 2초 이후이고 재생 중일 때 시청 이벤트를 기록합니다.
인스타그램은 고유 게시물 링크를 식별할 수 있고 화면에 절반 이상 1초 표시된 게시물을 기록합니다.
광고·숨겨진 추천 게시물·DM은 집계에서 제외합니다. 검색 결과 썸네일과 스토리는 게시물로 세지 않습니다.
최근 3,000개 식별자에 대해서 계정별 중복 집계를 억제하며, 집계 식별자는 해시로 저장합니다.
기준에 도달하면 소리·진동/알림 메시지, 휴식 화면을 선택한 설정대로 적용합니다.
휴식 만료 시점을 저장하므로 계정 전환·앱 재실행으로 대기를 초기화하지 않습니다.
휴식 화면에서는 영상 재생을 멈추며, 시간이 끝난 뒤 ‘계속하기’를 눌러 해제합니다.

### 보호

‘보호’에서 설정 비밀번호를 만들면 필터·휴식·기존 앱 잠금·보호 설정 변경이 잠깁니다.
비밀번호는 6자리 이상 숫자이며 Keychain에 소금값과 반복 해시를 저장합니다.
5회 입력 실패 시 30초 입력 대기를 적용합니다. 앱을 배경으로 보내면 설정 접근이 다시 잠깁니다.
이 비밀번호는 iOS 자체의 스크린 타임 암호를 설정하거나 대체하지 않습니다.

전체 버전에서 ‘성인 웹사이트 차단’을 켜고 스크린 타임을 연결하면
`ManagedSettings.webContent.blockedByFilter = .auto(...)`로 Apple의 성인 콘텐츠 필터를 요청합니다.
추가 차단 도메인도 입력할 수 있습니다. SNS 사용 잠금을 16분 해제해도 성인 사이트 필터와 삭제 제한은 유지합니다.
브라우저 버전은 내장 도메인 10개와 추가 입력한 도메인만 차단하며, 전체 성인 콘텐츠를 자동 분류하지 않습니다.

삭제·스크린 타임 권한 해제 보호에는 **가족 공유 자녀 기기와 보호자 승인 모드**를 사용합니다.
‘보호’에서 연결 전 가족 모드를 선택하면 `.child` 승인을 요청합니다.
‘앱 삭제 제한 · 기기 전체’는 해당 모드에서 `denyAppRemoval`을 요청하며 다른 앱의 삭제에도 영향을 줍니다.
보호자는 권한을 해제할 수 있습니다. 개인 `.individual` 모드에서는 사용자가 iOS 설정에서 권한을 해제할 수 있으며
앱이 그 스위치를 잠글 수 없습니다. 앱 내부 비밀번호를 시스템 권한 해제 방지로 표시하지 않습니다.
이미 승인된 모드를 바꾸려면 iOS에서 기존 고요의 권한을 해제하고 새 모드로 다시 연결하세요.

### 공부 기록

‘공부 → 타이머’에서 과목의 색상 재생 버튼을 누르면 집중 화면이 열립니다. 집중 화면의 일시정지 버튼으로 쉬고 재개할 수 있습니다. 공부 종료를 누르면 기록을 저장하고 별점을 매깁니다.
동시에 한 과목만 측정합니다. 상단에는 오늘 총시간, 각 과목 오른쪽에는 오늘 과목별 시간이 표시됩니다.
‘과목 편집’에서 과목 추가·이름·색상 변경·삭제가 가능합니다. 진행 중이거나 일시정지한 과목은 편집/삭제할 수 없습니다.
삭제한 과목의 이전 기록과 과목명은 남습니다. ‘통계’에서 오늘·이번 주·최근 기록을 볼 수 있습니다.
종료할 때 집중도를 1~5점으로 평가할 수 있으며 ‘나중에 평가’도 가능합니다.
최근 기록 또는 캘린더의 기록을 누르면 평가를 수정할 수 있습니다. 별점은 사용자가 직접 매기는 평가입니다.
기존 0.2 기록은 시간·과목 ID를 유지하며 새 색상은 자동, 별점은 미평가로 읽습니다.
저장된 시작 시각으로 앱이 닫혀 있는 시간과 화면이 꺼진 시간도 포함합니다. 실제 학습 여부를 자동 판별하는 기능은 아닙니다.
기록이 자정을 지나면 오늘/주간 합계에서는 해당 기간에 겹친 시간만 계산합니다.
‘공부 중 SNS 잠그기’를 켜면 고요 브라우저 진입을 막고, 전체 버전은 미리 선택한 앱·카테고리·사이트도 잠급니다.
공부를 시작할 때 이전의 임시 앱 잠금 해제는 폐기하므로 공부 종료 후 남은 해제 시간이 되살아나지 않습니다.

### 투두·캘린더

‘공부 → To-do’에서 날짜를 선택하고 ‘할 일 추가’를 누르세요. 제목·과목·날짜·완료 상태를 저장합니다.
원형 체크 버튼으로 완료를 전환하고, 제목을 누르면 수정할 수 있습니다. 스와이프/길게 누르기로 삭제할 수 있습니다.
‘전체 날짜의 할 일 보기’를 켜면 지난 날짜와 미래 날짜의 할 일을 함께 표시합니다.
‘캘린더’는 월 이동·오늘 이동·날짜 선택을 지원합니다. 날짜 셀에는 공부한 분과 일정 표식을 표시합니다.
선택한 날짜 아래에 과목별 시간, 할 일, 시간 지정 일정, 겹치는 공부 구간과 별점을 함께 표시합니다.
자정을 넘긴 한 구간은 각각의 날짜 합계에 겹친 시간만 더하고, 기록 행에는 원래 전체 구간 길이를 보여줍니다.
미래 날짜에는 진행 중인 공부의 미래 시간을 더하지 않습니다.
투두와 캘린더는 같은 기기 내 데이터를 사용합니다. iCloud·Apple 캘린더 동기화나 예약 푸시 알림은 포함하지 않습니다.

### 화면·CSS 예시

보내주신 참고 화면에 맞춰 공부 화면은 초록색 총시간 영역과 과목별 코랄·보라·청록 재생 버튼을 사용합니다.
진입 대기·휴식 화면은 짙은 회색 배경과 보라색 강조, 분:초 표시를 사용합니다.
`Docs/study-example.html`을 브라우저로 열면 과목별 타이머·별점·30초 대기 디자인 예시를 조작할 수 있습니다.
CSS는 `Docs/study-example.css`에 별도로 있습니다. 예시 기록은 브라우저에만 저장하며 iOS 앱 기록과 별개입니다.
CSS는 웹 예시용이고 실제 아이폰 앱 화면은 SwiftUI로 작성되어 있습니다. Live Activity 기능은 포함하지 않습니다.

## 아이폰 설치

Mac, Xcode 16 이상, 연결할 아이폰이 필요합니다.

### 먼저 브라우저 버전 설치

1. ZIP을 풀고 `Goyo.xcodeproj`를 Xcode로 여세요.
2. `Config.xcconfig`에서 `GOYO_BUNDLE_ID`를 고유한 값으로 바꾸세요. 예: `com.yourname.goyo`.
3. Xcode 위쪽 Scheme을 **GoyoBrowser**로 선택하세요.
4. `GoyoBrowser` Target의 Signing & Capabilities에서 본인의 Team을 선택하세요.
5. 아이폰을 연결하고 실행 기기로 선택한 뒤 Run을 누르세요. 아이폰에서 요구하면 개발자 모드를 활성화하세요.

이 버전은 Family Controls 권한 없이 앱 안의 웹 필터와 진입 대기를 사용합니다.
개인 무료 개발자 계정의 설치·서명 조건은 Xcode에서 안내하는 내용을 따릅니다.

### 기존 앱 전체 잠금이 포함된 버전 설치

1. Apple Developer Program 계정의 Team을 사용하세요.
2. `Config.xcconfig`의 `GOYO_APP_GROUP`을 본인의 App Group으로 바꾸세요. 예: `group.com.yourname.goyo`.
3. **Goyo**, **GoyoShieldConfiguration**, **GoyoShieldAction**, **GoyoActivityMonitor** 네 Target에 같은 Team과 같은 App Group을 설정하세요.
4. 네 Target의 Family Controls entitlement와 프로비저닝을 확인하세요. 필요한 entitlement 파일은 포함되어 있습니다.
5. Scheme을 **Goyo**로 선택하고 실제 아이폰에 Run 하세요.
6. 고요의 ‘앱 잠금’ 탭에서 ‘스크린 타임 연결’을 누르고 잠글 앱을 선택하세요.
7. ‘선택한 앱 잠그기’를 켜세요.
8. 잠긴 앱을 사용하려면 홈에서 고요를 열어 ‘앱 잠금’ 탭에서 기다린 뒤, 홈에서 원하는 앱을 여세요.

잠금 안내 화면의 버튼은 기존 앱을 닫습니다. 고요를 자동으로 실행하는 버튼으로 구현하지 않았습니다.
앱 그룹은 함께 해제됩니다. 개별 앱 실행마다 새로운 대기 화면을 자동으로 삽입하는 방식은 아닙니다.
자동 해제 구간은 16분입니다. Apple의 DeviceActivity 예약은 최소 15분 이상의 구간을 요구합니다.
TestFlight/App Store 배포는 개발자 계정의 배포 서명과 Family Controls 배포 entitlement 준비 후 진행합니다.

## 실제 적용 범위

기존 YouTube·Instagram·디시 앱의 내부 화면에 코드를 삽입하지 않습니다. 필터를 사용하려면 고요 안에서 해당 서비스를 열어주세요.
웹 광고 필터는 알려진 광고 네트워크와 DOM 광고 영역을 대상으로 합니다. 영상 콘텐츠에 합쳐진 광고까지 제거하지는 않습니다.
유튜브·인스타그램의 웹 구조가 바뀌면 `Resources/Filters.js`의 선택자를 갱신해야 합니다.
로그인, 2단계 인증, 메시지·영상 재생의 동작은 플랫폼 웹 버전이 제공하는 범위를 따릅니다.
로그인 데이터는 WKWebView의 기기 내 데이터 저장소를 사용하며 별도 서버로 전달하는 코드는 없습니다.
이 소스에는 구독, 유료 잠금, 원격 분석 또는 자체 백엔드가 없습니다.

## 검증 상태

`VALIDATION.md`에 실행한 검사와 미실행 항목을 구분했습니다.
2026-10-11 KST 기준 GitHub의 macOS/Xcode에서 전체 Goyo(확장 3개 포함)와 GoyoBrowser의 iPhone용 Release 빌드가 성공했습니다. Apple 계정의 인증서·프로비저닝을 아직 제공받지 않아 서명·실기기 스크린 타임 동작은 검증하지 않았습니다. 시뮬레이터 실행 검사는 Actions 결과를 확인해주세요.
필터는 합성 웹 페이지에서 검사했으며, 실제 로그인한 유튜브·인스타그램 계정에서 검사한 결과가 아닙니다.

Mac에서 다음 명령으로 빌드 구성을 확인할 수 있습니다.

```sh
xcodebuild -project Goyo.xcodeproj -scheme GoyoBrowser -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build
xcodebuild -project Goyo.xcodeproj -scheme Goyo -sdk iphoneos CODE_SIGNING_ALLOWED=NO build
```

## 0.4 허용 앱과 연락 메뉴

‘앱 잠금 → 스크린 타임·잠금 설정’에서 연결한 뒤 잠글 앱과 허용 앱을 선택합니다.
허용 목록에서는 개별 앱과 웹사이트를 선택하세요. 허용 앱·웹사이트는 각각 50개까지이며 카테고리 전체를 예외로 지정하지 않습니다.
‘공부 중 허용 앱만 사용’은 허용 목록 밖의 앱과 웹사이트를 잠급니다. 전화·메시지가 필요하면 이 두 앱을 허용 목록에 추가하세요.

홈의 ‘허용 메뉴’에서 메뉴 이름, HTTPS 주소 또는 설치 앱의 공개 URL 스킴, 사진 아이콘을 저장합니다.
스크린 타임의 앱 토큰은 URL 스킴을 제공하지 않으므로 허용 선택만으로 실행 링크를 자동 생성하지 않습니다.
설치 앱은 iOS가 해당 앱으로 전환합니다. 다른 앱의 네이티브 화면을 고요 내부에 삽입하지 않습니다.
전화는 `tel:` 연결로 시스템 확인 후 진행하고, 문자는 `MFMessageComposeViewController`를 앱 안에 표시합니다.
연락처 선택은 `CNContactPickerViewController`가 선택한 번호 하나만 전달합니다.

기존 YouTube 앱의 탭을 수정하는 기능은 없습니다. 쇼츠 탭 제거는 고요 안의 YouTube 웹 화면에 적용됩니다.
아이콘 변경은 Apple의 대체 앱 아이콘 API로 제공하는 네 가지 번들 디자인을 사용합니다. 메뉴 타일 아이콘은 선택 사진으로 직접 변경할 수 있습니다.
